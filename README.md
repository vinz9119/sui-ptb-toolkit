# Sui PTB Toolkit

A TypeScript-oriented toolkit design for building and validating programmable transaction block workflows.

## Goals
- Keep transaction construction separate from business logic.
- Make input validation explicit.
- Provide deterministic transaction descriptions for tests and review.
- Isolate network/client integration behind small interfaces.

## Status
Scaffold stage. The repository currently focuses on architecture and testable transaction intent; it does not claim a deployed application or a completed SDK integration.
